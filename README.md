# تطبيق حضور الخدام - كنيسة السيدة العذراء والشهيدة كاترين

تطبيق احترافي متكامل مبني بتقنية Flutter لنظامي Android و iOS لتسجيل ومتابعة حضور خدام الكنيسة.

## المميزات الرئيسية
1. **نظام صلاحيات مخصص للأمناء:**
   - **أمين عام الخدمة (Super Admin):** إشراف عام على جميع الفروع، إضافة وتعديل الفروع، توليد تواريخ الجُمَع، واستخراج التقارير المجمعة.
   - **أمين الفرع (Branch Admin):** يرى فقط خدام فرعه، ويسجل حضورهم، ويتابع افتقادهم.
2. **تسجيل الدخول وحفظ الجلسة:**
   - صفحة تسجيل دخول مع اختيار الفرع.
   - ميزة "حفظ تسجيل الدخول على هذا الهاتف" للبقاء متصلاً دائماً.
3. **توليد تواريخ الجُمَع (Friday Engine):**
   - توليد شهر بشهر أو لسنة كاملة (2026 / 2027).
4. **رصد الحضور الأسبوعي السريع:**
   - 3 خانات لكل خادم: القداس الإلهي، حضور الخدمة، اجتماع الخدام.
   - 3 حالات: حاضر، عذر، غائب.
5. **تنبيهات الافتقاد الذكية:**
   - كشف تلقائي للخدام المتغيبين لأسبوعين (تنبيه أولي) أو 3 أسابيع فأكثر (تنبيه عاجل).
   - أزرار مباشرة للاتصال الهاتفي والمراسلة عبر واتساب.
6. **تصدير التقارير (Excel):**
   - تصدير فوري لملف Excel (CSV متوافق بالكامل مع اللغة العربية UTF-8 BOM).

## بناء نسخة الـ APK
- **عبر GitHub Actions:** عند رفع المشروع لأي مستودع GitHub، سيعمل ملف العمل في `.github/workflows/build_apk.yml` تلقائياً على بناء ملف `app-release.apk` وتحميله مجاناً.
- **محلياً:** قم بتشغيل الأمر:
  ```bash
  flutter build apk --release
  ```
